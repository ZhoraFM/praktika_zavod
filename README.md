Предметная область — завод

ООО «Завод» — металлообрабатывающее предприятие, на котором работают сотрудники, про которых хранится стандартная информация: фамилия, имя, отчество, адрес проживания, телефон, а также год получения образования и квалификация (должность).

Ежедневно на завод обращаются заказчики (юридические и физические лица). Все они проходят обязательную регистрацию, при которой в базу данных заносятся стандартные реквизиты (наименование/ФИО, адрес).

Также вносится информация о требуемой продукции и особых условиях заказа. Бывает, что у заказчика имеется несколько заказов на предприятии по различным позициям.

Каждый заказчик может размещать заказы на заводе не один раз, нуждаясь в различной продукции. Все заказы фиксируются, при этом устанавливается описание, определяется стоимость, запоминается дата заказа.

Для постоянных заказчиков предусмотрены скидки на продукцию.

Бизнес-процессы

1. Регистрация нового заказчика
2. Учёт заказов (обращений за продукцией)
3. Выпуск продукции по заказу (формирование накладной)
4. Учёт квалификации персонала и кадров
